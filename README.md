# Сайт-визитка Романа Жуковича

Учебный проект: личный сайт-портфолио плюс один демо-пример работы.
Всё свёрстано на чистом HTML и CSS — без фреймворков, сборщиков и картинок.

## Что где лежит

```
portfolio/
├── index.html          ← главная страница (сайт-визитка), открывать её
├── style.css           ← все стили главной страницы
├── README.md           ← этот файл
└── demo/
    └── cafe/
        ├── index.html  ← демо-проект: лендинг пекарни «Тёплый хлеб»
        └── style.css   ← его стили
```

## Как посмотреть

Двойной клик по `index.html` — страница откроется в браузере.
Всё работает без интернета: шрифты системные, картинок нет, внешних библиотек нет.

## Как править текст

1. Открой `index.html` в блокноте или в VS Code.
2. Найди нужный блок по комментарию: `<!-- ===== ОБО МНЕ ===== -->`.
3. Меняй только текст между тегами — сами теги не трогай.
4. Сохрани файл и обнови страницу в браузере (F5).

## Цвета и размеры

Все цвета и отступы собраны в начале `style.css` в блоке `:root`.
Поменял одну строку — поменялся весь сайт. Например:

```css
--ink: #14161a;   /* основной цвет текста и кнопок */
--bg:  #fbfbfa;   /* цвет фона */
```

## Что уже сделано правильно

- Адаптив: страница перестраивается под планшет и телефон.
- Доступность: у ссылок видимый фокус при навигации с клавиатуры, у картинок-заглушек стоит `aria-hidden`.
- Семантика: `header`, `main`, `section`, `article`, `footer` — не просто набор `div`.
- Нет лишнего: ни одного внешнего файла, который может не загрузиться.
